# File Converter GUI App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the bash `fileconvert` script with a PySide6 app (queue, per-format options, custom presets, output naming) that opens from the launcher or Dolphin's right-click menu, plus a compatible `fileconvert` CLI.

**Architecture:** Pure modules (`filetypes`, `presets`, `options`, `commands`, `naming`, `store`) decide what to run and where outputs go, and are tested without Qt. `queue.py` runs jobs with `QProcess`; `gui/` draws the window; `menus.py` generates Dolphin service menus from presets; `instance.py` hands files to an already running window.

**Tech Stack:** Python 3.11+ (system has 3.14), PySide6 6.11, pytest 9, pytest-qt 4.5; ffmpeg/ffprobe, ImageMagick 7 (`magick`), Ghostscript, LibreOffice (`soffice`), `setsid`, `flock`.

**Spec:** `docs/superpowers/specs/2026-10-02-gui-app-design.md`

## Global Constraints

- Runtime dependency is `pyside6` only; everything else is stdlib. Presets/settings are JSON.
- Conversion tools are optional; a missing tool disables formats that need it, with tooltip text `Install <tool> to enable`.
- Config file: `$XDG_CONFIG_HOME/dolphin-file-converter/presets.json` (default `~/.config/...`). LibreOffice profile: `$XDG_CACHE_HOME/dolphin-file-converter/lo-profile`.
- Built-in preset ids are exactly the current 28: `audio:{mp3,aac,ogg,opus,flac,wav}`, `video:{mp4,mp4-small,webm,mkv,gif}`, `image:{png,jpg,webp,avif,gif,ico,pdf}`, `office:{pdf,docx,odt,xlsx,ods,csv,pptx,odp}`, `pdf:{png,jpg}`.
- Untouched built-in options must produce the same encoder settings as the bash script (`fileconvert` at commit `6f0b9c2`).
- Outputs are written to a hidden temp dir `.fileconverter-XXXXXX` inside the output folder and moved into place on success; nothing partial is ever left behind.
- Originals are only ever moved to Trash (`QFile.moveToTrash`), never deleted, and only after that job succeeded.
- Single-instance server name: `dolphin-file-converter-<uid>`.
- Commands: `fileconverter` (GUI), `fileconvert` (CLI). Package dir: `fileconverter/`.
- Commit style: Conventional Commits, subject ≤50 chars, no `Co-Authored-By` trailers.
- Run tests from the repo root with `python -m pytest`.

## Review Focus

1. **Overwrite onto the source + "move originals to Trash"** (e.g. `pic.png` → PNG, same folder, clash `overwrite`): the new output must survive; the original must not be trashed when it *is* the output. Test in Task 7.
2. **Awkward filenames**: spaces, unicode, a leading `-`, `[1]` and `%` in the name (`magick` treats `[..]` as a frame selector, ffmpeg/magick treat `%d` as a sequence on output). Conversions must still succeed. Tests in Tasks 4 and 7.
3. **Output folder unusable** (chosen folder deleted or read-only): job ends `FAILED` with a readable error; no crash, other jobs continue. Test in Task 7.
4. **Dropping things that aren't convertible** (a `.txt`, a file with no extension, a folder of photos): unsupported files are skipped with a message naming them; folders expand recursively to their supported files. Test in Task 11.
5. **Cancel or failure mid-LibreOffice / mid-ffmpeg**: no `.fileconverter-*` dirs left behind and no orphaned `soffice.bin`. Test in Task 7.

### Task 2: Options and quality mapping

**Files:**
- Create: `fileconverter/options.py`, `tests/test_options.py`
- Modify: `fileconverter/presets.py` (fill built-in default `options`)

**Interfaces:**
- Consumes: `Preset`, `BUILTINS`, `BUILTIN_BY_ID`.
- Produces:
  - `options.Options` — frozen dataclass: `quality: int | None = None`, `max_height: int | None = None`, `resize: str | None = None` (`"50%"` or `"1600x1600"`), `trim_start: float | None = None`, `trim_end: float | None = None`, `strip_metadata: bool = False`, `pdf_dpi: int = 150`; `from_dict(d) -> Options` (ignores unknown keys, raises `ValueError` on bad `resize`), `to_dict() -> dict` (omits `None`/defaults).
  - `options.applicable(preset: Preset) -> frozenset[str]` — names of fields the GUI shows.
  - `options.encoder_quality(fmt: str, quality: int) -> int | str` — see table.
  - `options.parse_time(text: str) -> float | None` — `""`→`None`; accepts `ss`, `mm:ss`, `hh:mm:ss`, decimals; raises `ValueError` otherwise.
  - `options.format_time(seconds: float) -> str` — `"1:05"`, `"1:02:03"`.
  - `options.MAX_HEIGHTS = (None, 2160, 1440, 1080, 720, 480)`, `options.PDF_DPIS = (72, 150, 300)`.

Quality mapping (`q` 0–100, round half up):

| fmt | result |
|---|---|
| mp4 | CRF `round(35 - q*19/100)` |
| webm | CRF `round(45 - q*25/100)` |
| mp3 | `-q:a` `round(9 - q*9/100)` |
| ogg | `-q:a` `round(q*10/100)` |
| aac | `"{k}k"`, k = `64 + q*256/100` rounded to nearest 8 |
| opus | `"{k}k"`, k = `48 + q*208/100` rounded to nearest 8 |
| jpg, webp, avif | `max(1, q)` |

`applicable`: quality for `mp3 aac ogg opus mp4 webm jpg webp avif`; `max_height` for video `mp4 webm gif` (not mkv); `trim_start/trim_end` for audio + video except `mkv`; `resize` for all `image:*`; `strip_metadata` for audio, video (incl. mkv), image; `pdf_dpi` for `pdf:*`; office presets: empty set.

Built-in defaults: `audio:mp3` q78, `audio:aac` q50, `audio:ogg` q50, `audio:opus` q38, `video:mp4` q79, `video:mp4-small` q37, `video:webm` q52, `image:jpg` q90, `image:webp` q90, `image:avif` q70, `pdf:*` `pdf_dpi` 150.

### Task 4: Command builders and tool detection

**Files:**
- Create: `fileconverter/commands.py`, `tests/conftest.py`, `tests/test_commands.py`, `tests/test_conversions.py`

**Interfaces:**
- Consumes: `Preset`, `Options`, `encoder_quality`, `BUILTINS`.
- Produces:
  - `commands.TOOLS = ("ffmpeg", "ffprobe", "magick", "gs", "soffice")`
  - `commands.detect_tools(which=shutil.which) -> dict[str, bool]`
  - `commands.required_tools(preset: Preset) -> tuple[str, ...]` — audio/video: `("ffmpeg","ffprobe")`; image: `("magick",)`; pdf: `("magick","gs")`; office: `("soffice",)`.
  - `commands.build(preset: Preset, src: Path, workdir: Path, *, lo_profile: Path) -> list[str]` — writes into `workdir`: ffmpeg/magick → `workdir/out.<ext>`; pdf → `workdir/page-%d.<ext>`; office → `--outdir workdir`. ffmpeg argv always includes `-hide_banner -nostdin -y -progress pipe:1 -nostats`. Office argv is prefixed `["flock", f"{lo_profile}.lock", "soffice", f"-env:UserInstallation=file://{lo_profile}", "--headless", "--convert-to", ext, "--outdir", str(workdir), str(src)]`.
  - `commands.probe_argv(src: Path) -> list[str]` — ffprobe for `format=duration`, `default=nw=1:nk=1`.
  - `commands.parse_duration(text: str) -> float | None` — `"N/A"`/empty → `None`.
  - `commands.parse_progress(text: str) -> float | None` — last `out_time_us=` in text, as seconds.

Argv per format = the bash script's `case` block at commit `6f0b9c2`, with these substitutions:
- quality values from `encoder_quality`;
- `max_height` H on mp4/webm: replace `-vf scale=trunc(iw/2)*2:trunc(ih/2)*2` with `-vf scale=-2:'min(ih,H)'` (webm gets the same filter); on gif, chain it before `fps=12` as `scale=-2:'min(ih,H)'`;
- `trim_start`/`trim_end`: `-ss S` before `-i`, `-to E` after `-i` (E relative to source start; with `-ss` before `-i` use `-to E-S`);
- `strip_metadata`: ffmpeg `-map_metadata -1` (mkv: also `-map_chapters -1`); magick `-strip` before the output;
- `resize` R: magick `-resize R` (for `WxH` append `>` so it only shrinks);
- `pdf_dpi`: `-density DPI`.
- `magick` never sees the user's filename: `build` reads through a symlink `workdir/.in<src.suffix>` → `src` (created by `build`), so `[`, `%` and a leading `-` in names can't be misparsed. First-frame presets read `.in<suffix>[0]`. The queue collects only `out.<ext>` / `page-*.<ext>` from `workdir`, never the symlink.

### Task 7: Job queue

**Files:**
- Create: `fileconverter/queue.py`, `tests/test_queue.py`

**Interfaces:**
- Consumes: `Preset`, `Options`, `commands.build/probe_argv/parse_duration/parse_progress`, `naming.render/resolve`.
- Produces:
  - `queue.JobState(Enum)`: `PENDING` (added, not started), `WAITING`, `RUNNING`, `DONE`, `FAILED`, `CANCELLED`, `SKIPPED`; `queue.FINISHED = {DONE, FAILED, CANCELLED, SKIPPED}`.
  - `queue.OutputSettings` — frozen dataclass: `folder: Path | None` (None = source folder), `pattern: str`, `clash: str`, `trash_originals: bool`.
  - `queue.Job` — dataclass: `id: int, src: Path, kind: str, preset: Preset, output: OutputSettings, state: JobState, progress: float | None` (0–1, `None` = indeterminate), `outputs: list[Path]`, `log: str`, `error: str`.
  - `queue.JobQueue(QObject)`: signals `job_added(int)`, `job_changed(int)`, `job_removed(int)`, `drained()`; `__init__(self, workers: int, lo_profile: Path, parent=None)`; `add(src: Path, kind: str, preset: Preset, output: OutputSettings) -> int`; `set_preset(job_id, preset)` and `set_output(job_id, output)` (only `PENDING`/finished); `start(job_ids: Iterable[int] | None = None)` (None = all `PENDING` → `WAITING`); `cancel(job_id)`; `retry(job_id)` (finished → `WAITING`); `remove(job_id)` (cancels if running); `clear_finished()`; `job(job_id) -> Job`; `jobs() -> list[Job]`; property `workers` (settable, takes effect on next scheduling).

Behavior:
- Scheduler runs at most `workers` jobs; at most one office job at a time regardless of `workers`.
- Starting a job: render stem with `naming.render(pattern, name=src.stem, preset_name=preset.name, today=date.today())`; folder = `output.folder or src.parent`; if clash is `skip` and the single output already exists → `SKIPPED` without running. Create workdir with `tempfile.mkdtemp(prefix=".fileconverter-", dir=folder)`; failure → `FAILED` with error `Can't write to <folder>`.
- audio/video: run `probe_argv` first (own `QProcess`), then the ffmpeg command; progress = `parse_progress(stdout) / effective_duration` where effective duration accounts for trim. Never block the GUI thread.
- Every command is started as `setsid <argv…>`; cancel sends `SIGTERM` to the process group (`os.killpg`).
- On success: move outputs with `naming.resolve` (`page-N` → stem `"{stem}-{N}"`, single page → `stem`); `os.replace` for overwrite; then remove workdir. Zero outputs → `FAILED` (`"<tool> produced no output"`). On any exit (fail/cancel) remove workdir.
- `trash_originals`: after `DONE`, call `QFile.moveToTrash(str(src))` unless any output path resolves to the same file as `src`.
- `log` collects stderr (and soffice stdout); `error` is the last non-empty stderr line.
- Emit `drained` when no job is `WAITING`/`RUNNING` after at least one job finished.
